# Лабораторная работа №6: Передача данных по протоколу UDP

Репозиторий содержит реализацию клиент-серверного взаимодействия без предварительного установления соединения по протоколу UDP (User Datagram Protocol) на языке Python с использованием программного интерфейса BSD-сокетов. Разработано в рамках курса **«Сети ЭВМ и телекоммуникации»**.

- **Учебное заведение:** ЮЗГУ
- **Кафедра:** Программной инженерии
- **Группа:** ПО-32б

## Особенности реализации

- В строгом соответствии с заданием: **каждая строка исходного кода содержит подробный комментарий**.
- Использование протокола датаграмм: `socket.SOCK_DGRAM`.
- Прием и отправка данных осуществляются посредством атомарных операций `recvfrom()` и `sendto()`.
- Отсутствие процедур рукопожатия (handshake) и подтверждения доставки (ACK).
- Фиксированный заголовок протокола UDP размером 8 байт (Source Port, Destination Port, Length, Checksum).
- Сервер принимает строку, логирует параметры клиента, переводит строку в верхний регистр (капс) и возвращает ответ.
- В репозиторий включен реальный дамп сетевого обмена `udp_exchange.pcap`.

## Запуск

1. Запуск сервера:
```bash
python udp_server.py
```

2. Запуск клиента:
```bash
python udp_client.py
```
